# Visualisations de données avec RawGraphs

Le but de cet exercice est d'illustrer plusieurs concepts vus en cours sur la visualisation de données non-spatiales, au moyen de Rawgraphs.

## Présentation de rawgraphs

[Rawgraphs](https://www.rawgraphs.io) est une interface web opensource permettant de produire différentes types de diagramme, sans compétences informatique. L'interface permet de téléverser ses données, de choisir entre plusieurs types de représentations, de modifier leurs paramètres, et d'exporter le diagramme produit sous différents formats.
